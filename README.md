# The Dynamic Daily Quote Generator

A small front-end project that fetches and displays a random quote from a public API.

## Features
- Fetch a new random quote with the click of a button
- Show a loading state while the request is in progress
- Display an error message if the fetch fails
- Use a clean, responsive card-based layout

## Run the Project
1. Open the project folder in a browser.
2. Double-click `index.html` or run a local static server.
3. Click the `Get New Quote` button.

## Files
- `index.html` — app structure, styles, and JavaScript logic

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
